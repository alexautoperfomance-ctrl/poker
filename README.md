# Холдем с друзьями
Безлимитный техасский холдем на 2–9 игроков (только люди, только виртуальные фишки). Хост создаёт стол и шлёт ссылку, друзья вводят ник и садятся.
Сеть: WebRTC P2P через публичный брокер PeerJS; браузер хоста — авторитетный сервер (раздаёт карты, каждому шлёт только его карманные карты). Состояние стола хранится в localStorage хоста.
Тесты: `npm test` (оценщик, сайд-поты, двойная доска), `python tests/e2e.py` (4 браузера через Playwright, нужен локальный http-сервер, переменная URL).
