# Холдем с друзьями
Безлимитный техасский холдем на 2–9 игроков (только люди, только виртуальные фишки). Хост создаёт стол и шлёт ссылку, друзья вводят ник и садятся.
Сеть: WebRTC P2P через публичный брокер PeerJS; браузер хоста — авторитетный сервер (раздаёт карты, каждому шлёт только его карманные карты). Состояние стола хранится в localStorage хоста.
Тесты: `npm test` (оценщик, сайд-поты, двойная доска), `python tests/e2e.py` (4 браузера через Playwright, нужен локальный http-сервер, переменная URL).

## Связь
По умолчанию — ретранслятор через публичные MQTT-брокеры (WSS): broker.emqx.io:8084, broker.hivemq.com:8884, test.mosquitto.org:8081. Хост слушает все сразу, игрок берёт первый доступный. Если ни один не отвечает — запасной путь P2P (PeerJS/WebRTC).
Шифрование: у каждого игрока свой ключ ECDH P-256 → AES-GCM-256, рукопожатие подписано ECDSA-ключом хоста, отпечаток ключа — в ссылке `#t=КОД.ОТПЕЧАТОК`. Счётчики сообщений защищают от повторов.
E2E с локальным брокером: `cd tests && npm i aedes ws && node broker.cjs` (порт 9883), затем `python tests/e2e.py`.
